# 工位动作打卡

一个单文件的工位微运动打卡页。**零依赖、零构建**，直接丢到 GitHub Pages 就能用。

## 用

打开页面 → 每做完一个动作点一次 `+` → 每天完成目标轮数即可。

- **一轮 = 四个动作连着做**，约 90 秒，不起身、不出汗
- **完成轮数 = 四个动作里的最小次数**（少做一个就不算完整一轮）
- 数据按天自动分开；跨天自动切换，不用手动重置

## 动作

| # | 动作 | 量 | 说明 |
|---|---|---|---|
| 1 | 踝泵 | 上勾下压 ×15 | 桌下，看不见 |
| 2 | 臀肌收紧 | 5 秒 ×3 | 衣服挡着 |
| 3 | 收腹坐直 | 5 秒 ×5 | **正常呼吸，别憋气** |
| 4 | 肩胛后缩下沉 | 5 秒 ×5 | 幅度 1–2 cm |
| 5 | 下巴回收 | 5 秒 ×5 | 进阶，默认关闭 |
| 6 | 握力等长 | 10 秒 ×3 | 进阶，默认关闭 |

## 数据

**数据只存在你当前浏览器的 `localStorage` 里，不会上传到任何服务器。**

- **导出 CSV** —— 给表格软件 / 脚本读
- **导出 JSON** —— 完整备份，可再导入
- **导入 JSON** —— 恢复或迁移到另一台设备

> ⚠️ 换设备、换浏览器、清理浏览器数据之前，**先导出 JSON**。

CSV 格式：

```csv
date,踝泵,臀肌收紧,收腹坐直,肩胛后缩下沉,下巴回收,握力等长,完成轮数
2026-10-21,3,3,3,3,0,0,3
```

## 部署到 GitHub Pages

```bash
git init
git add .
git commit -m "desk check-in"
gh repo create <repo-name> --public --source=. --push
gh api -X POST "repos/<you>/<repo-name>/pages" \
  -f "source[branch]=main" -f "source[path]=/"
```

然后访问 `https://<you>.github.io/<repo-name>/`。

## 注意

等长收缩时**全程正常呼吸，不要憋气**。有血压相关病史的人尤其要注意。
出现麻木、刺痛，或小腿**单侧**肿痛发热，停止并就医。
